## 简介

这是一个基于 Chrome 扩展的 AI 翻译工具，使用 DeepSeek AI API 提供文本翻译功能。该扩展支持多种翻译模式，包括图标翻译、即时翻译和关闭划词模式，同时提供网页翻译功能和翻译历史记录管理。

该翻译界面采用现代化的响应式设计，具有直观的用户交互体验，支持实时翻译、历史记录管理和多种语言配置。

## 故障排除指南

### 常见问题及解决方案

#### 1. API 密钥相关问题

**问题症状**：
- 翻译功能无法使用
- 显示 API 密钥错误信息

**解决步骤**：
1. 检查 API 密钥格式是否正确
2. 确认 API 密钥具有翻译权限
3. 验证网络连接是否正常
4. 重新输入并保存 API 密钥

#### 2. 翻译结果为空

**问题症状**：
- 输入文本后无翻译结果
- 输出区域显示空白

**解决步骤**：
1. 检查输入文本是否包含有效字符
2. 确认翻译模式设置正确
3. 验证 API 服务状态
4. 查看浏览器开发者工具中的错误信息

#### 3. 历史记录不显示

**问题症状**：
- 翻译历史面板为空
- 无法查看之前的翻译记录

**解决步骤**：
1. 检查浏览器存储权限
2. 确认 Chrome 存储 API 正常工作
3. 清除浏览器缓存后重试
4. 检查扩展权限设置

#### 4. 复制功能失效

**问题症状**：
- 点击复制按钮无响应
- 翻译结果无法复制到剪贴板

**解决步骤**：
1. 检查浏览器剪贴板权限
2. 确认页面具有写入剪贴板权限
3. 尝试刷新页面后重试
4. 检查是否有其他扩展程序干扰
